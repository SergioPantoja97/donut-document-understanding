# Ejecución Streamlit para Donut

## 1) Instalar dependencias
```bash
pip install -r requirements_streamlit.txt
```

## 2) Ejecutar la aplicación
```bash
streamlit run app.py
```

## 3) Abrir en el navegador
Normalmente Streamlit abre en una URL como:
```text
http://localhost:8501
```

## 4) Uso
1. Carga una imagen (`png`, `jpg`, `jpeg` o `webp`).
2. Pulsa **Procesar documento**.
3. Observa la imagen, el JSON resultante, el tiempo de inferencia y las secuencias generadas.
